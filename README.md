# nba-draft-value-analysis-2005-2016
Excel analytics project evaluating the value of NBA first-round draft picks from 2005-2016 using career performance metrics.
NBA Draft Value Analysis

Overview

This Excel project analyzes the value of first-round NBA draft selections from 2005–2016 using career performance statistics through the 2021–22 season. 
The goal is to identify historical draft trends and evaluate which draft positions generated the greatest long-term value.

Research Question

How much career value does each draft position produce, and which players most significantly outperformed historical expectations?

Key Findings:
Lottery selections produced the highest average career Win Shares.
Chris Paul generated the highest Value Above Expected in the dataset.
Draft position is negatively correlated with career Win Shares, but several mid-first-round selections significantly outperformed expectations.
Career outcomes vary considerably even among lottery picks.

Limitations:
Career statistics are cumulative through the 2021–22 season.
Earlier draft classes have had more time to accumulate Win Shares.
Win Shares represent an estimate of player contribution rather than a direct count of games won.

Future Improvements:
Compare players after their first six NBA seasons.
Incorporate salary data to evaluate return on investment.
Expand the analysis to include second-round selections.
